# Architecture Decisions

ADRs capture decisions that are cross-cutting, precedent-setting, or hard to reverse — the *why* behind the architecture. They are append-only: status can change (Superseded, Deprecated) but history is not rewritten. Feature-scoped decisions live in their feature doc, not here.
