## What It Does

Build a stronger daily capture → clarify → deliver → retrieve experience and explain that value on the website. Explore AI and automation only where they shorten that workflow; retain all owner ideas without turning them into simultaneous delivery promises.

**Website update (2026-09-27):** EN/ES landing copy and site-level SEO were updated on this branch. The [four-chapter concept](/marketing/website-concept/) includes the proposed floating navigation, media shot list, and release-aware copy; [Kai](/marketing/brand-and-kai/#ready-to-use-image-prompt) has a pixel-art exploration prompt. Layout, new footage, and mascot art are not implemented; visual review remains pending.

## Decisions

| Decision                                                                                      | Why                                                                                                  | Alternatives Considered                                                          |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Propose workflow and website first                                                            | Makes existing value easier to use and understand                                                    | Full visual rebrand or competitor feature parity                                 |
| No watermark on the free tier                                                                 | The monetization ADR already forbids charging for local features; the competitor is free without one | Keep the watermark for marketing (rejected: the share page does that job better) |
| No Tauri rewrite                                                                              | The gap is the pipeline, already solved; Recordly is Electron too                                    | Rewrite for idle RAM and bundle size (rejected, see the ADR)                     |
| Ship Windows as a recording-only beta                                                         | The build works; the first objection in every thread is "Windows?"                                   | Wait for screenshot parity                                                       |
| Captions on Parakeet TDT v3, not Whisper                                                      | The owner already ships it multilingual elsewhere                                                    | Whisper bake-off first                                                           |
| Explore captions before summaries or agents                                                   | Immediate comprehension benefit and reusable transcription foundation                                | Generic AI chat, autonomous editing first                                        |
| Close the visible feature gap (GIF, one beautiful default) but not full cursor-effects parity | Cheap items that change the first impression; parity is infinite and not what Kaipu sells            | Chase Screen Studio polish item by item                                          |
| Keep Kai optional and supporting                                                              | Preserve existing recognition                                                                        | Rename product or couple mascot to AI                                            |
