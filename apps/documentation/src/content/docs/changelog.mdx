# Changelog

| Date       | Feature                     | Type | Summary                                                                                                                                                                                                                                                                                               |
| ---------- | --------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-06-26 | Tray start + bar placement    | ✨   | The Capture Panel's **Start** now records (opens the main window and runs its start) instead of just opening it. And the floating control bar appears on the **screen you're recording** on multi-monitor (resolved from the source), not wherever the cursor is. |
| 2026-06-26 | Dock / app-switcher control   | 🔧   | Fixed the app vanishing from the Dock & ⌘-Tab after a recording — hiding the main window dropped it on macOS and it never came back; the hub now re-asserts the activation policy + brings the app forward on stop. Added a persisted **"Show in Dock & app switcher"** setting (off = menu-bar/tray-only) — the app's first real persisted setting (new `settings-store`). |
| 2026-06-26 | Synced recording settings     | 🔗   | Source, capture toggles and the selected mic are now a **single source of truth** in the main process, broadcast to every window — toggle Camera (or anything) in the Record page and it reflects in the Capture Panel, and vice versa. The camera bubble follows the global Camera toggle, so it works from the tray too. |
| 2026-06-26 | Camera bubble                 | 🎥   | A floating, draggable webcam **bubble** (its own circular always-on-top window) that the screen recording captures because it sits on screen — no compositing. Driven by the Camera toggle. The control bar is now excluded from recordings (`setContentProtection`) while the bubble is kept capturable. [Pipeline](/desktop/recording-pipeline) |
| 2026-06-26 | Shared CTA glow + hardware encode | 💄   | Extracted the onboarding button's accent glow into a `--glow-accent` token and applied it to every primary CTA (ui `Button`, `RecordButton`, Record-page Stop, onboarding) — dropped on disabled/dark states. Centered the Capture Panel record button. Also requested hardware H.264 encode (`prefer-hardware`, VideoToolbox) to avoid the software OpenH264 path. |
| 2026-06-26 | Close the post-countdown start race | 🐛   | After `3·2·1`, the recorder is `"starting"` (acquiring streams) while the window is still visible — the Start button could be clicked again, double-triggering. The blocking overlay now stays up (spinner) through that gap, `useScreenRecorder.start` guards re-entry via `sessionRef` (no double session), and the button is disabled. Countdown number now uses the accent colour. |
| 2026-06-26 | Recording UI: timers + Pause/Stop | 💄   | Made "we are recording" obvious everywhere: the global activity now carries `elapsedSeconds`, so the Record page shows a header card with a live timer + a Pause / Stop-recording row + a LOCKED source badge, and the Capture Panel shows a red "Recording — mm:ss" banner. The floating widget is larger (bigger timer, taller pill, roomier centered buttons). |
| 2026-06-26 | Recording state across windows | 🔒   | The hub now broadcasts a single recording-activity state to every window, so the Record page and Capture Panel reflect an in-progress recording (heading, inert controls) and can't start a second one — the tray button becomes Stop. New windows query the current state on mount. [Pipeline](/desktop/recording-pipeline) |
| 2026-06-26 | Jump to the recording after saving | ✨   | On stop, the bar shows a brief "Saving…" while the encoder flushes and the file finalizes (metadata, thumbnail, name), then navigates straight to the recording's detail page before the main window reappears — no flash of the Record page. |
| 2026-06-26 | Control bar widget polish      | 💄   | Fixed the floating bar over light backgrounds (transparent backdrop), removed an accidental scrollbar, and matched the reference design: squarer pill + buttons, timer before the mic meter, separator, shortcut hint, no focus ring. |
| 2026-06-26 | Screen recording + control bar | 🎥   | Built the real recording core on mediabunny: seekable MP4 (H.264/AAC) captured in the hidden main window and streamed to disk **positionally** (`fd.write@position`), finalized into the vault with a thumbnail. Added a floating always-on-top **control bar** (live timer, 5-bar mic meter, pause/resume, stop) in its own window, coordinated by a main-process hub (Option A). Vault is now extension-aware. Camera PiP/watermark are designed-for follow-ups. [Pipeline](/desktop/recording-pipeline) |
| 2026-06-26 | Desktop architecture docs   | 📝   | Documented how the desktop app works today: [Main Process Architecture](/desktop/main-process-architecture), [IPC Contract](/desktop/ipc-contract), [Library Vault](/desktop/library-vault), [Permissions & Onboarding](/desktop/permissions-and-onboarding). Grounded in real `src/main` + `src/shared` code with file refs.                                                                          |
| 2026-06-26 | Docs: Elysia → Hono migration | 🔄   | Project uses Hono/oRPC only. Migrated the Elysia vocabulary to Hono across `architecture/`: rewrote `application-layer` around the real `listTodos` use case + its two real consumers (oRPC route in `server-hono`, TanStack serverFn in `web-hono`), dropping non-existent apps/website + apps/mobile and reframing "mobile-safe" as "client-safe"; replaced Elysia route examples with real oRPC/Hono in `repository-pattern`, `application-services-layer`, `constants-pattern`, `schemas-implementation`; relabeled diagrams in `authentication` + `error-handlers`. Zero Elysia mentions remain. |
| 2026-06-26 | Mediabunny over FFmpeg      | 🏛️   | Decided the real recording core builds on mediabunny (WebCodecs) instead of porting the legacy MediaRecorder + FFmpeg stack — real seekable MP4 in one pass, ~8× faster HW encode, ~70 kB vs ~50–80MB binaries, no base64/remux. FFmpeg kept only as an optional offline tool. [ADR 0001](/architecture/decisions/0001-mediabunny-over-ffmpeg) · [Pipeline](/desktop/recording-pipeline)                                  |
| 2026-06-26 | Scrollbar standard          | 💄   | Themed scrollbar app-wide in `base.css` (thin, rounded, hover-brightening) so every scroll area is consistent. Fixed the screen-picker modal scrollbar overlapping its tiles (`scrollbar-gutter`), and dropdown menus (`Select`, mic picker) that clipped/grew instead of scrolling.                |
| 2026-06-26 | Shared source selection     | 🐛   | Record page now loads real screen sources on mount and preselects the primary screen (fixes "No source selected" + disabled Start Recording). Extracted `useSourceSelection` so the Record page and Capture Panel derive the source identically — no more hardcoded placeholder. Added hook tests.    |
| 2026-06-26 | UI de-port + house style    | ♻️   | Rebuilt the shared `ui/` primitives and a few feature components to original structure — a `cx()` helper plus `data-*` variant attributes and CSS custom properties — removing copied CSS. Reviewed the whole app (renderer, main, preload, shared) for similarity to the reference recorders; clean. |
| 2026-06-15 | Renderer architecture       | 🏛️   | Documented the pages/features/ui/shell layout and the page→rename→split migration workflow. [Docs](/desktop/renderer-architecture)                                                                                                                                                                    |
| 2026-06-15 | Record / Library / Settings | 💄   | Migrated the Record, Library and Settings screens (UI-only) + icon sidebar and router error handling.                                                                                                                                                                                                 |
