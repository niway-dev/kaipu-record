## Welcome

Welcome to the **Kaipu** documentation. A modern full-stack monorepo built with DDD + Hexagonal Architecture, TanStack Start, Hono, and oRPC — deployed on Cloudflare Workers.

---

## Quick Start

### Prerequisites

- **Bun** - Package manager and runtime
- **PostgreSQL** - Database

### Installation

```bash
# Install dependencies
bun install

# Check tooling, then sign in — there are no .env files to create
bun run setup
infisical login

# Run database migrations
bun run db:push

# Start development servers
bun run dev:web-hono      # Web app (port 3001)
bun run dev:server-hono   # API server (port 3000)
```

## Tech Stack

### Monorepo Structure

- **Package Manager**: Bun
- **Build Tool**: Turbo
- **Monorepo**: Turborepo with workspace packages

### Frontend (`apps/web-hono`)

- **Framework**: React with TanStack Start
- **Routing**: TanStack Router
- **State Management**: TanStack Query
- **API Client**: oRPC OpenAPILink (contract-first)
- **UI Library**: shadcn/ui with TailwindCSS
- **Validation**: Zod v4

### Backend (`apps/server-hono`)

- **Framework**: Hono (native Cloudflare Workers)
- **API layer**: oRPC with contract-first approach
- **Database**: PostgreSQL with Drizzle ORM
- **Authentication**: Better Auth
- **Validation**: Zod v4

### Documentation (`apps/documentation`)

- **Framework**: Astro Starlight

## Key Concepts

### Schema-Based Architecture

Zod schemas are the source of truth, defined in `@kaipu/domain` and reused across server and client:

```typescript
export const todoBaseSchema = z.object({
  id: z.uuid(),
  title: z.string().min(1),
  completed: z.boolean(),
  createdAt: z.coerce.date(),
});

export const createTodoSchema = todoBaseSchema.pick({ title: true });

export type Todo = z.infer<typeof todoBaseSchema>;
export type CreateTodo = z.infer<typeof createTodoSchema>;
```

### Contract-First API (oRPC)

The API contract is defined once in `apps/server-hono/src/contract/` and imported by the web app for full type safety without code generation:

```typescript
// Contract defines routes, input/output schemas, REST paths
export const todoContract = {
  list: oc.route({ method: "GET", path: "/todos" }).input(paginationQuerySchema).output(...),
  create: oc.route({ method: "POST", path: "/todos", successStatus: 201 }).input(createTodoSchema).output(...),
};
```

### Same-Origin Proxy Architecture

The web Worker proxies all API requests through itself to the API Worker, solving cookie-based auth on Cloudflare Workers. In production, Cloudflare Service Bindings handle Worker-to-Worker communication with no public DNS.

See [Stack: Hono + oRPC](/stack/hono) for the full architecture walkthrough.

## Security

- **HttpOnly Cookies** — Session tokens stored server-side
- **Server-Side Validation** — All auth checks on the server
- **Same-Origin Proxy** — CORS not needed for web (proxied)
- **SQL Injection Prevention** — Drizzle ORM parameterizes queries
- **XSS Protection** — React's built-in sanitization
