## How to sign

On your first pull request, add this sentence as a comment, with your GitHub username:

> — @your-username

Once is enough: it covers that pull request and every later Contribution. If you contribute on
behalf of a company, say so in the same comment and name the company; Niway may ask for a
signed copy from someone authorized to bind it.
